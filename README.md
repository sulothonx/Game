# 🎮 ภารกิจพิชิตโลกคอมพิวเตอร์ (Computer World Adventure)
> **สื่อการเรียนรู้เชิงสร้างสรรค์ วิชา วิทยาการคำนวณ สำหรับนักเรียนชั้นประถมศึกษาปีที่ 1**  
> เกมผจญภัย 2D แนว Adventure สีสันสดใส ตัวละครการ์ตูน Chibi น่ารัก ภาพคมชัด เสียงประกอบตื่นเต้น และเชื่อมต่อฐานข้อมูลคะแนนลง Google Sheets แบบอัตโนมัติ

---

## 🌟 จุดเด่นและฟีเจอร์สำคัญของเกม

1. **ภาพการ์ตูน 2D Chibi น่ารักสดใส**: มีตัวละครให้เลือก 3 สไตล์ ได้แก่ น้องกล้า 👦, น้องแก้ว 👧 และ หุ่นยนต์จิ๋วบิ๊ทบ็อท 🤖
2. **ผจญภัยในโลกคอมพิวเตอร์ 5 ด่าน**:
   - 🌲 **ด่านที่ 1: ป่าแป้นพิมพ์ (Keyboard Forest)** — เรียนรู้หน้าที่ของแป้นพิมพ์ (Keyboard)
   - 🏙️ **ด่านที่ 2: เมืองจอภาพ (Monitor City)** — เรียนรู้หน้าที่ของจอภาพ (Monitor)
   - 🕳️ **ด่านที่ 3: ถ้ำเมาส์ (Mouse Cave)** — เรียนรู้หน้าที่ของเมาส์ (Mouse)
   - 🎵 **ด่านที่ 4: หุบเขาเสียง (Speaker Valley)** — เรียนรู้หน้าที่ของลำโพง (Speaker)
   - 🏰 **ด่านที่ 5: ปราสาทคอมพิวเตอร์ (Computer Castle)** — เรียนรู้วิธีปิดเครื่องคอมพิวเตอร์อย่างถูกต้อง
3. **ระบบอ่านออกเสียงโจทย์ภาษาไทย (Text-to-Speech)**: มีปุ่ม 🔊 "ฟังเสียงโจทย์" ช่วยให้เด็กชั้น ป.1 ที่กำลังฝึกอ่านหนังสือ สามารถกดฟังเสียงอ่านโจทย์และตัวเลือกได้อย่างเข้าใจง่าย
4. **ระบบพลังชีวิต 3 ดวง (❤️❤️❤️)**: ตอบถูกรับ 20 คะแนน (คะแนนเต็ม 100) ตอบผิดเสียหัวใจ 1 ดวง พร้อมคำอธิบายที่เข้าใจง่าย และให้โอกาสลองตอบใหม่ หากหัวใจหมดระบบจะฟื้นพลังเต็ม 3 ดวงและให้เริ่มด่านปัจจุบันใหม่โดยไม่ตัดกำลังใจของเด็ก
5. **รองรับทุกหน้าจอ (Responsive & Touch Controls)**: เล่นได้ลื่นไหลทั้งบนคอมพิวเตอร์ (ปุ่มลูกศร / A-D / Space) แท็บเล็ต และโทรศัพท์มือถือ (มีปุ่ม D-Pad สัมผัสบนหน้าจอ)
6. **ระบบเสียงสังเคราะห์ Web Audio API**: เสียงกระโดด เก็บเหรียญ ตอบถูก ดนตรีประกอบสดใส โดยไม่ต้องโหลดไฟล์ภายนอก หมดปัญหาเรื่องเสียงไม่ขึ้น
7. **เชื่อมต่อฐานข้อมูล Google Sheets**: บันทึก วันที่-เวลา, ชื่อ-นามสกุล, ชั้น, เลขที่, คะแนน, จำนวนข้อที่ถูก, ระดับการเรียนรู้ และสถานะ ลงแผ่นงาน `GameScores` โดยอัตโนมัติ พร้อมระบบป้องกันการกดบันทึกซ้ำ

## 🐙 ขั้นตอนที่ 2: การนำโค้ดขึ้น GitHub ผ่าน GitHub Desktop

1. เปิดโปรแกรม **GitHub Desktop** บนคอมพิวเตอร์ของคุณ
2. เข้าเมนู **File** ➔ เลือก **Add Local Repository...** (หรือกด `Ctrl + O`)
3. คลิกปุ่ม **Choose...** แล้วเลือกโฟลเดอร์เกม:
   ```
   c:\Users\Lenovo\Desktop\เกม
   ```
4. หากโปรแกรมขึ้นเตือนว่า *"This directory does not appear to be a Git repository"*:
   - ให้คลิกที่ลิงก์สีฟ้า **create a repository**
   - ใส่ชื่อ Name: `computer-world-adventure` (หรือชื่อตามต้องการ)
   - คลิกปุ่ม **Create Repository**
5. ตรวจสอบไฟล์ทั้งหมดในแท็บ **Changes** ด้านซ้าย (`index.html`, `style.css`, `script.js`, `Code.gs`, `README.md`)
6. ที่ช่อง Commit summary ด้านล่างซ้าย พิมพ์:
   ```text
   Initial commit - ภารกิจพิชิตโลกคอมพิวเตอร์ ป.1
   ```
7. คลิกปุ่มสีน้ำเงิน **Commit to main** (หรือ `master`)
8. คลิกปุ่ม **Publish repository** ด้านบน
   - นำเครื่องหมายถูกออกจากช่อง *Keep this code private* (เพื่อให้เปิดใช้งาน GitHub Pages ได้ฟรี)
   - คลิก **Publish Repository**

## 🌐 ขั้นตอนที่ 3: การเปิดเว็บไซต์เกมออนไลน์ด้วย GitHub Pages

1. เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่ GitHub ใน Repository ของคุณ
2. คลิกแท็บ **Settings** (รูปฟันเฟืองด้านบน)
3. เมนูด้านซ้าย เลือกหัวข้อ **Pages**
4. ในส่วน **Build and deployment**:
   - แหล่งที่มา (Source): เลือก **Deploy from a branch**
   - สาขา (Branch): เลือก **`main`** (หรือ `master`) และโฟลเดอร์เลือก **`/(root)`**
5. คลิกปุ่ม **Save**
6. รอประมาณ 1-2 นาที แล้วรีเฟรชหน้าเว็บ จะปรากฏแถบสีเขียวพร้อมข้อความ:
   ```
   Your site is live at https://<username>.github.io/<repo-name>/
   ```
7. สามารถนำลิงก์นี้ ส่งให้นักเรียนเล่นผ่านคอมพิวเตอร์ห้องแล็บ แท็บเล็ต หรือมือถือของผู้ปกครองได้ทันที!

## 🔒 นโยบายความปลอดภัยและข้อควรระวัง (Security)

- **ไม่มีการเก็บรหัสผ่าน**: ตัวเกมและโค้ดไม่มีการฝังรหัสผ่านส่วนตัว หรือ API Secret Key ใด ๆ
- **ข้อมูลนักเรียน**: จัดเก็บเฉพาะข้อมูลสำหรับประเมินผลการเรียนรู้ ได้แก่ ชื่อ-นามสกุล, ชั้น, เลขที่ และคะแนน เพื่อความเป็นส่วนตัวและความปลอดภัยของเยาวชน
- **ระบบป้องกันข้อมูลซ้ำซ้อน**: มีตัวแปร Lock ในฝั่ง JavaScript และ `LockService` ในฝั่ง Google Apps Script เพื่อป้องกันกรณีเด็กกดปุ่มซ้ำ
- **ระบบสำรองข้อมูล (Offline Resilience)**: หากเกิดสัญญาณอินเทอร์เน็ตหลุด ตัวเกมจะบันทึกผลลงใน `localStorage` ของเครื่องทันที ทำให้ผลคะแนนไม่สูญหาย

## ❓ คำถามที่พบบ่อย (FAQ)

- **Q: นักเรียนกดแล้วไม่มีเสียงทำอย่างไร?**  
  *A:* บราวเซอร์สมัยใหม่ (เช่น Chrome/Safari) มีนโยบายบล็อกเสียงอัตโนมัติ ให้คลิกที่หน้าจอด้านล่างหรือปุ่มเริ่มเล่น 1 ครั้ง ระบบเสียง Web Audio จะเปิดทำงานทันที
- **Q: เล่นบนมือถือปุ่มกดสัมผัสไม่ขึ้น?**  
  *A:* ตัวเกมออกแบบปุ่มสัมผัส (◀, ▶, ⏫) ให้แสดงผลโดยอัตโนมัติเมื่อตรวจพบการสัมผัสหรือหน้าจอขนาดพกพา
- **Q: สามารถพิมพ์เกียรติบัตรออกมาได้ไหม?**  
  *A:* เมื่อเล่นจบครบ 5 ด่าน จะมีปุ่ม **"🖨️ พิมพ์ / บันทึกผล"** ซึ่งถูกปรับแต่ง CSS สำหรับสั่งพิมพ์ลงกระดาษ A4 หรือบันทึกเป็น PDF สวยงามได้ทันที
